# 🎙️ Bongo Type (বঙ্গ টাইপ) — Universal Voice Typing Assistant

> **Bongo Type** হলো একটি শক্তিশালী, আধুনিক এবং রিয়েল-টাইম ভয়েস টাইপিং অ্যাসিস্ট্যান্ট (Voice Typing Assistant), যা বিশেষভাবে **বাংলা (Bangla)**, **বাংলিশ (Banglish / Romanized Bengali)** এবং **আরবি (العربية)** ভাষার জন্য ডিজাইন করা হয়েছে। 

Windows 11-এর `Win + H` ভয়েস টাইপিংয়ের মতো এটি সরাসরি আপনার স্ক্রিনের সামনে ভাসমান অবস্থায় (Floating Pill) থাকে এবং কথা বলা মাত্রই সক্রিয় যেকোনো অ্যাপে স্বয়ংক্রিয়ভাবে টাইপ করে দেয়। এছাড়া অ্যান্ড্রয়েড ফোনের জন্যও রয়েছে একটি পূর্ণাঙ্গ অ্যাপ্লিকেশন।

## ✨ প্রধান বৈশিষ্ট্যসমূহ (Key Features)

1. **ইউনিভার্সাল টেক্সট ইনজেকশন (Universal Text Injection)**:
   - যেকোনো অ্যাপ্লিকেশনে (যেমন: VS Code, Notepad, MS Word, Google Chrome, WhatsApp Desktop, ইত্যাদি) কথা বললে নিজে থেকেই কার্সরে লেখা টাইপ হয়ে যায়।
2. **ফ্লোটিং অ্যাসিস্ট্যান্ট পিল (Windows 11 Fluent Floating Pill)**:
   - কমপ্যাক্ট, ফ্রেমহীন, ড্র্যাগেবল (যেখানে খুশি টেনে রাখা যায়) এবং অলওয়েজ-অন-টপ (Always-on-top) ডিজাইন।
3. **আনলিমিটেড একটানা কথা বলা (Continuous Dictation)**:
   - সাধারণ ভয়েস টাইপিংয়ের মতো এক বাক্য পর বন্ধ হয় না; আপনি যতক্ষণ ইচ্ছা কথা বলবেন, ততক্ষণ এটি একটানা টাইপ করতে থাকবে।
4. **তিনটি ডেডিকেটেড ভাষা মোড (Dedicated Language Support)**:
   - 🇧🇩 **বাংলা (Bangla)**: নিখুঁত বাংলা ইউনিকোড অক্ষর এবং বাক্য শেষে নির্ভুল দাঁড়ি (।) সংযোগ।
   - 🔤 **বাংলিশ (Banglish)**: মুখে বাংলায় বলবেন, কিন্তু স্ক্রিনে নিখুঁত ইংরেজি হরফে (Latin script) রোমানাইজড লেখা উঠবে (যেমন: *"Ami ekhon kotha bolchi"*), কোনো প্রকার বিকৃতি ছাড়া।
   - 🇸🇦 **আরবি (العربية)**: সম্পূর্ণ আরবি ইউনিকোড ও ডান-থেকে-বাম (RTL) পাঙ্কচুয়েশন।
5. **৬০ এফপিএস অডিও ওয়েভফর্ম (60 FPS Audio Waveform)**:
   - মাইক্রোফোনে কথা বলার তীব্রতার সাথে সাথে স্মুথ ওয়েভফর্ম এনিমেশন।
6. **গ্লোবাল শর্টকাট কি (Global Hotkeys)**:
   - যেকোনো উইন্ডোতে থাকা অবস্থায় `CTRL + SPACE` অথবা `ALT + SPACE` চাপলেই ভয়েস টাইপিং শুরু হয়ে যাবে।
7. **সিস্টেম ট্রে সাপোর্ট (Windows System Tray)**:
   - ব্যাকগ্রাউন্ডে সবসময় চালু থাকে এবং টাস্কবার ট্রে থেকে নিয়ন্ত্রণ করা যায়।

## 📱 অ্যান্ড্রয়েড ফোনে ব্যবহারের নির্দেশিকা (Android Usage Guide)

### ১. ইন্সটলেশন (Installation)
1. উপরের ডাউনলোড লিংক থেকে **`BongoType-v1.0.0.apk`** ফাইলটি আপনার ফোনে ডাউনলোড করুন।
2. ফাইলটিতে ট্যাপ করে **Install** করুন (প্রয়োজনে "Install from unknown sources" পারমিশন দিন)।
3. অ্যাপটি ওপেন করার পর মাইক্রোফোন পারমিশন (Record Audio Permission) চাইলে **Allow** করে দিন।

### ২. ব্যবহারের নিয়মাবলী (How to Use)
- **মাইক্রোফোন চালু করা**: স্ক্রিনের ওপরের ফ্লোটিং পিলের মাইক্রোফোন আইকনে (🎙) ট্যাপ করুন। এটি সাথে সাথে নীল রঙ ধারণ করবে এবং ওয়েভফর্ম সক্রিয় হবে।
- **ভাষা নির্বাচন**: ড্রপডাউন থেকে আপনার পছন্দমতো ভাষা সিলেক্ট করুন:
  - `বাংলা` — মুখে বাংলা বললে বাংলা অক্ষরে টাইপ হবে।
  - `Banglish` — মুখে বাংলা বললে ইংরেজি হরফে বাংলিশ টাইপ হবে (যেমন: *"Kemon acho"*).
  - `العربية` — আরবি উচ্চারণে আরবি হরফে টাইপ হবে।
- **অ্যাপ ওয়ার্কবেঞ্চ সিমুলেশন**: অ্যাপটির ভেতর Notepad, VS Code, WhatsApp, Word বা Chrome নির্বাচন করে সরাসরি টাইপিং পরীক্ষা করুন।
- **মিনি মোড (Floating Mini Mode)**: ডান পাশের ফুলস্ক্রিন আইকনে চাপ দিলে অ্যাপটি সম্পূর্ণ মিনিমাইজড ফ্লোটিং পিলে পরিণত হবে।
- **ক্লিপবোর্ড কপি**: কথা বলা শেষ হলে এক ট্যাপে সম্পূর্ণ লেখা কপি করে যেকোনো সোশ্যাল মিডিয়ায় বা মেসেঞ্জারে পাঠিয়ে দিন।

## 💻 উইন্ডোজ কম্পিউটারে ব্যবহারের নির্দেশিকা (Windows Desktop Guide)

Windows 10 অথবা Windows 11-এ Bongo Type ব্যবহার করার পদ্ধতি:

### ১. প্রয়োজনীয় সফটওয়্যার
- **Python 3.11 বা তার নতুন সংস্করণ** ([python.org](https://www.python.org/downloads/) থেকে ডাউনলোড করুন। ইন্সটল করার সময় *"Add Python to PATH"* বক্সে টিক দিন)।

### ২. প্রজেক্ট সেটআপ ও রান করা
প্রথমে রিপোজিটরিটি ক্লোন করুন অথবা ZIP ডাউনলোড করে আনজিপ করুন:

```bash
# গিটহাব থেকে ক্লোন করুন
git clone https://github.com/labibmahmud236-alt/bongo-type.git
cd bongo-type/windows_desktop

# প্রয়োজনীয় লাইব্রেরিসমূহ ইন্সটল করুন
pip install -r requirements.txt

# অ্যাপ্লিকেশনটি চালু করুন
python main.py
```

### ৩. উইন্ডোজে সরাসরি ব্যবহারের ধাপসমূহ
1. `python main.py` রান করার সাথে সাথে আপনার স্ক্রিনের শীর্ষে একটি স্বচ্ছ, গ্লাস ডিজাইনের ফ্লোটিং ভয়েস বার চলে আসবে।
2. আপনার কীবোর্ডে **`CTRL + SPACE`** চাপুন (অথবা ফ্লোটিং পিলের মাইকে ক্লিক করুন)।
3. যেকোনো অ্যাপ (Notepad, Chrome, VS Code, WhatsApp) ওপেন করে কার্সার রাখুন এবং কথা বলতে শুরু করুন।
4. আপনি কথা বলার সাথে সাথে স্বয়ংক্রিয়ভাবে সেখানে টাইপ হতে থাকবে।
5. টাইপিং থামাতে পুনরায় **`CTRL + SPACE`** চাপুন অথবা মাইকে ক্লিক করুন।
6. উইন্ডোজ টাস্কবারের ঘড়ির পাশে সিস্টেম ট্রে আইকন থেকে সেটিংস, পজ (Pause) কিংবা এক্সিট করতে পারবেন।

### ৪. এক ক্লিকে পোর্টেবল এক্সি (.exe) ফাইল তৈরি
যদি পাইথন ছাড়া সরাসরি ক্লিক করে চালানোর মতো সফটওয়্যার বানাতে চান:

```bash
pip install pyinstaller

pyinstaller --noconsole --onefile \
  --name "BongoType" \
  --add-data "settings;settings" \
  --add-data "speech;speech" \
  --add-data "audio;audio" \
  --add-data "typing;typing" \
  --add-data "ui;ui" \
  --add-data "animations;animations" \
  --add-data "tray;tray" \
  --add-data "hotkeys;hotkeys" \
  main.py
```
বিল্ড শেষ হলে `windows_desktop/dist/` ফোল্ডারে **`BongoType.exe`** তৈরি হয়ে যাবে, যা যেকোনো উইন্ডোজ কম্পিউটারে সরাসরি চলবে।

## ⚙️ সেটিংস ও কনফিগারেশন (Settings)

ফ্লোটিং বারের সেটিংস অপশন থেকে আপনি পরিবর্তন করতে পারবেন:
- **Global Shortcut**: `ctrl+space`, `alt+space`, অথবা `windows+h`
- **Default Language**: বাংলা, Banglish, অথবা আরবি
- **Typing Speed**: টাইপিং স্পিড নিয়ন্ত্রণ (মিলি-সেকেন্ডে)
- **Speech Engine**: Google Speech Recognition API / OpenAI Whisper / Gemini API
- **Always On Top**: সফটওয়্যারটি সবসময় অন্যান্য সব উইন্ডোর ওপরে ভাসমান থাকবে কি না

## 🛠️ টেকনোলজি স্ট্যাক (Technology Stack)

- **Android Client**: Kotlin, Jetpack Compose, Material 3, Android SpeechRecognizer, Coroutines & StateFlow
- **Windows Desktop Client**: Python 3.11+, PyQt6, Win32 SendInput API, PyAutoGUI, SoundDevice, NumPy
- **Speech & Audio**: Google Speech Recognition, Custom Phonetic Transliteration Engine, Real-time RMS Waveform
