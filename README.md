# 🎙️ Bongo Type (বঙ্গ টাইপ) — Universal Voice Typing Assistant

> **Bongo Type** হলো একটি শক্তিশালী, আধুনিক এবং রিয়েল-টাইম ইউনিভার্সাল ভয়েস টাইপিং অ্যাসিস্ট্যান্ট (Universal Voice Typing Assistant), যা বিশেষভাবে **বাংলা (Bangla)**, **বাংলিশ (Banglish / Romanized Bengali)** এবং **আরবি (العربية)** ভাষার জন্য নির্মিত।

---

## 🚀 নতুন ফিচার: ইউনিভার্সাল মেসেঞ্জার-স্টাইল কিবোর্ড বাবল (Universal Keyboard Bubble)

📱 আপনার মোবাইলের **যেকোনো অ্যাপে (যেমন: WhatsApp, IMO, Messenger, Telegram, Facebook, Chrome, SMS ইত্যাদি)** টাইপিং করার জন্য চ্যাটবক্সে ক্লিক করার সাথে সাথে স্ক্রিনে **মেসেঞ্জারের মতো একটি ভাসমান ভয়েস বাবল (Floating Mic Bubble)** চলে আসবে! 

- **মাইকে এক ট্যাপ**: বাবলের মাইকে ট্যাপ করলেই আপনার কথা শোনা শুরু হবে।
- **স্বয়ংক্রিয় টাইপিং**: কথা শেষ হওয়া মাত্রই সরাসরি সংশ্লিষ্ট অ্যাপের ইনপুট বক্সে/চ্যাটবক্সে লেখাটি টাইপ বা পেস্ট হয়ে যাবে!
- **ইনস্ট্যান্ট সেন্ড**: আপনি সাথে সাথেই সেন্ড বাটনে ক্লিক করে পাঠিয়ে দিতে পারবেন।
- **ভাষা পরিবর্তন**: বাবলের ছোট ল্যাঙ্গুয়েজ ট্যাগে ট্যাপ করে তাৎক্ষণিক **বাংলা ↔ Banglish ↔ আরবি** পরিবর্তন করা যায়।

## ✨ প্রধান বৈশিষ্ট্যসমূহ (Key Features)

1. **ইউনিভার্সাল কিবোর্ড বাবল (Universal Keyboard Floating Bubble)**:
   - IMO, WhatsApp, Telegram, Messenger সহ যেকোনো অ্যাপে কিবোর্ড ওপেন হলেই স্বয়ংক্রিয়ভাবে একটি ভাসমান বাবল উপস্থিত হয়।
   - সরাসরি সক্রিয় চ্যাটবক্সে টেক্সট ইনজেক্ট করে দেয়।
2. **Windows 11 স্টাইল ফ্রেমহীন ভয়েস বার (Fluent Voice Bar)**:
   - কম্পিউটারে `Win + H` কিংবা অ্যান্ড্রয়েডে স্ক্রিনের উপরে অলওয়েজ-অন-টপ ড্র্যাগেবল গ্লাস ডিজাইন।
3. **তিনটি ডেডিকেটেড ভাষা মোড**:
   - 🇧🇩 **বাংলা (Bangla)**: নিখুঁত বাংলা ইউনিকোড অক্ষর এবং বাক্য শেষে নির্ভুল দাঁড়ি (।) সংযোগ।
   - 🔤 **বাংলিশ (Banglish)**: মুখে বাংলায় বলবেন, কিন্তু স্ক্রিনে নিখুঁত ইংরেজি হরফে রোমানাইজড লেখা উঠবে (যেমন: *"Ami ekhon kotha bolchi"*), কোনো প্রকার বিকৃতি ছাড়া।
   - 🇸🇦 **আরবি (العربية)**: সম্পূর্ণ আরবি ইউনিকোড ও ডান-থেকে-বাম (RTL) পাঙ্কচুয়েশন।
4. **৬০ এফপিএস লাইভ অডিও ওয়েভফর্ম (60 FPS Audio Waveform)**:
   - মাইক্রোফোনে কথা বলার সাথে সাথে নিখুঁত রিয়েল-টাইম সাউন্ড তরঙ্গ।
5. **ক্রস-প্ল্যাটফর্ম সাপোর্ট**:
   - অ্যান্ড্রয়েড ডিভাইসের জন্য ফুল সার্ভিস ও উইন্ডোজ কম্পিউটারের জন্য PyQt6 + Win32 API ভিত্তিক ডেক্সটপ অ্যাপ।

### ১. ইনস্টলেশন
1. [BongoType-v1.1.0.apk](https://github.com/labibmahmud236-alt/bongo-type/releases/download/v1.1.0/BongoType-v1.1.0.apk) ডাউনলোড করে ইনস্টল করুন।
2. অ্যাপটি ওপেন করে মাইক্রোফোন পারমিশন দিন।

### ২. অটো-বাবল পারমিশন সক্রিয় করা (মাত্র ২ টি সহজ ধাপ):
অ্যাপের হোম পেজে **"Universal Keyboard Bubble"** কার্ডে ২টি অপশন দেখতে পাবেন:
1. **ফ্লোটিং পারমিশন (Display over other apps)**: *"অনুমতি দিন"* বাটনে ক্লিক করে Bongo Type-এর জন্য পারমিশন অন করুন।
2. **অ্যাক্সেসিবিলিটি সার্ভিস (Accessibility Service)**: *"চালু করুন"* বাটনে ক্লিক করে Accessibility মেন্যু থেকে **Bongo Type** সার্ভিসটি চালু (Enable) করে দিন।

### ৩. ব্যবহারের নিয়ম:
- এবার আপনার মোবাইলের **WhatsApp, IMO, Messenger, Telegram** বা যেকোনো অ্যাপ ওপেন করুন।
- কাউকে মেসেজ দেওয়ার জন্য চ্যাটবক্সে ক্লিক করুন (যেখানে কিবোর্ড আসে)।
- সাথে সাথে চ্যাটবক্সের পাশে একটি **নীল রঙের ভাসমান মাইক বাবল** দেখতে পাবেন।
- মাইকে একবার চাপ দিন, মুখে আপনার কথাটি বলুন।
- সাথে সাথে কথাটি আপনার চ্যাটবক্সে টাইপ হয়ে যাবে! এখন শুধু সেন্ড বাটনে চাপ দিন।

## 💻 উইন্ডোজ কম্পিউটারে ব্যবহারের নির্দেশিকা (Windows Desktop Guide)

Windows 10 অথবা Windows 11-এ Bongo Type ব্যবহার করার পদ্ধতি:

```bash
# গিটহাব থেকে ক্লোন করুন
git clone https://github.com/labibmahmud236-alt/bongo-type.git
cd bongo-type/windows_desktop

# ডিপেনডেন্সি ইনস্টল করুন
pip install -r requirements.txt

# চালু করুন
python main.py
```

- চালু করার পর কীবোর্ডে **`CTRL + SPACE`** চাপুন এবং যেকোনো উইন্ডোতে কথা বললে টাইপ হতে থাকবে।
